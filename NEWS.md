# flstockpile 0.1.0

* First version: `stockpile_stocks()`, `stockpile_sources()`,
  `stockpile_values()` and `stockpile_indices()` read the dataset tables,
  and `stockpile_flstock()` converts the values for one stock to an `FLStock`.

* The package is renamed from FLStockpile to flstockpile, to match its
  repository, which has moved to ices-tools-prod/flstockpile. The option
  that sets the dataset location is now `flstockpile.url`.
